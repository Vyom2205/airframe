### SnapSum

A modern, elegant calculator application for macOS featuring a beautiful minimalist interface with liquid glass effects. Type mathematical expressions naturally and see results instantly.

**Features:**
- 🎨 Beautiful UI with liquid glass effects and smooth animations
- ⚡ Real-time expression evaluation in a notepad-style editor
- 🔢 Smart arithmetic operations with parentheses and percentages
- 📊 Variable support (define and reuse values)
- 📏 Unit conversions (length, weight, area, temperature)
- 💱 Currency conversions (10 major currencies)
- 📅 Date & time math (add/subtract time, calculate differences, timezones)
- 📑 Multiple calculation sheets with elegant management
- 🗣️ Natural language support for intuitive calculations
- 📦 Easy installation via DMG

**Location:** `SnapSum/`

**Requirements:** macOS 13.0+, Swift 5.9+

**Download:** Get the latest [SnapSum.dmg](SnapSum/README.md#installation) or build from source.

See [SnapSum/README.md](SnapSum/README.md) for detailed documentation and usage examples.
