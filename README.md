### NumiCalculator

A Numi-inspired calculator application for macOS built with Swift and SwiftUI. This app provides a notepad-style interface where you can type mathematical expressions, text, and natural language calculations, with results displayed in a dedicated column.

**Features:**
- Notepad-style editor with real-time expression evaluation
- Basic arithmetic operations with parentheses and percentages
- Variable support (define and reuse values)
- Unit conversions (length, weight, area, temperature)
- Currency conversions (USD, EUR, GBP, JPY, and more)
- Time and date math (add/subtract time, calculate differences, timezone conversions)
- Multiple calculation sheets
- Natural language support for basic operations

**Location:** `NumiCalculator/`

**Requirements:** macOS 13.0+, Swift 5.9+

See [NumiCalculator/README.md](NumiCalculator/README.md) for detailed documentation and usage examples.
