### AirFrame - Procedural Airport Generator
A procedural airport layout generator that creates fictional, unique airport designs in minimalist blueprint style. Perfect for wallpapers and artistic visualizations.

**Features:**
- Procedural generation of completely fictional airports
- Full customization: runways, terminals, gates, taxiways
- Four terminal layouts: Linear, Pier, Satellite, Hybrid
- Blueprint-style rendering with three themes (Blueprint, Dark, White)
- Multiple aspect ratios (16:9, 9:16, 1:1)
- Export as SVG or PNG (4K resolution)
- Zero dependencies, works offline, GitHub Pages ready

**Try it:** Open `airport-blueprint/index.html` in your browser

**Documentation:** See [airport-blueprint/README.md](airport-blueprint/README.md) for detailed information

**Disclaimer:** All generated airports are fictional and created for artistic purposes only.
