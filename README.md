### Airport Blueprint Map
A minimalist web application for visualizing airport layouts using OpenStreetMap data. Similar to [city-roads](https://anvaka.github.io/city-roads/) but specifically designed for airports.

**Features:**
- Search airports by ICAO or IATA code
- Blueprint-style visualization with runways, taxiways, and terminals
- Multiple themes (Blueprint, Dark, White)
- Multiple aspect ratios (16:9, 9:16, 1:1)
- Export as SVG or PNG (4K resolution)

**Try it:** Open `airport-blueprint/index.html` in your browser or view the demo at `airport-blueprint/demo.html`

**Documentation:** See [airport-blueprint/README.md](airport-blueprint/README.md) for detailed information
